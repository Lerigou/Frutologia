# 🍉 Frutologia
 
Site responsivo desenvolvido em React que consome uma API pública para exibir informações nutricionais de diversas frutas — de forma simples, visual e acessível.
 
## 📋 Sobre o projeto
 
O Frutologia nasceu como projeto da disciplina de **Desenvolvimento Web** da faculdade, com o desafio de consumir uma API externa e construir um site totalmente responsivo. A proposta foi criar uma interface leve e intuitiva para consulta de dados nutricionais de frutas, unindo consumo de API, componentização em React e estilização com SCSS.
 
## 🛠️ Tecnologias utilizadas
 
- **React** (Create React App)
- **SCSS**
- **JavaScript**
- **HTML5 / CSS3**
- Consumo de **API REST** para dados nutricionais de frutas
## 🎯 Contexto de desenvolvimento
 
Este projeto foi criado em grupo como trabalho acadêmico, com os seguintes requisitos:
 
- Consumir uma API pública e exibir os dados de forma dinâmica
- Construir uma interface responsiva, adaptada a diferentes tamanhos de tela
- Aplicar boas práticas de componentização em React
## 🚀 Como rodar o projeto
 
```bash
# Clone o repositório
git clone https://github.com/Lerigou/Frutologia.git
 
# Acesse a pasta do projeto
cd Frutologia
 
# Instale as dependências
npm install
 
# Rode o projeto
npm start
```
 
O site estará disponível em `http://localhost:3000`.
